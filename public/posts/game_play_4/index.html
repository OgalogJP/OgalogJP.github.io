【ナナオリ】 クモレイド (HELL) について 【七つの大罪：Origin】

2026年9月30日

初めに#

この記事は深層のクモの巣レイド (HELL)の攻略についてまとめています。

適正外攻略且つ、無凸・低凸向けの内容になっています。

ゲームシーズン・バーションなど#

ver 2.1 ハーフアニバーサリー後半

闇蜘蛛装備とは#

闇蜘蛛装備はバースター向けの装備セットになっています。

闇蜘蛛装備のセット効果

真価を発揮するには属性バースト効率を盛る必要がありますが、セット効果の後半だけでも強力です。

闇蜘蛛装備の入手方法#

アプデで難易度が 1 つ追加され、HELL でレイド装備が落ちるようになりました。

レイド装備の入手方法は以下の通りです。

  • 精鋭ボスの討伐報酬 (ドロップレートはゲーム内を参照)
  • レイドクリア報酬
  • ミスティックトークン交換所の利用

深層のクモの巣 ( HELL ) の攻略#

ここからは私なりのレイド攻略についてまとめていきます。

  • 編成に炎 or 雷が 1 体必須
  • 落下に注意
  • 精鋭 3 体討伐
  • ラスボス頑張る

道中#

道中進むために、炎か雷のキャラが必須になります。

精鋭戦#

どの精鋭もあまり脅威ではありませんが “兵隊グモ” だけ面倒です。

シールドを頻繁に張ってくるため、火力を出すタイミングを意識しないと本体にダメージを与え辛いです。

ラスボス戦#

注意すべき攻撃は “ひっくり返って回転攻撃してくるやつ(?)” と “毒エリア散布攻撃” の 2 つです。

回転攻撃は威力がかなり高く、回避せずゴリ押すとかなり厳しい戦いになります。通常 2 回連続ですが、敵のシールド 2 回目以降は最大 3 回来るので釣られないようにします。

毒散布の方は毒ダメージのスタックが厄介で、スタック量次第では回復が間に合わずに死にます。毒攻撃が見えたら毒エリアと反対側に移動すると安全です。

即死攻撃に関しては必殺技の無敵でやり過ごすのが無難だと思います。

【ガントレット】 デリエリ#

バースト要らずのアタッカー。

注意点として、一連の流れの所要時間が短いことがあげられます。

これは他のキャラとローテを組んだ際、スキルの CD によってはローテ毎に打てない可能性が出てきます。

クールタイム短縮率を付けて調整することで回るようになったりします。

【魔導書】 デイジー#

武器は “誘惑の戦慄” を使用しています。6凸 でバックアタック時クリティカル耐性 40% 減になるため、デバフとしてはかなり良い効果だと思います。

運用上注意すべきなのはパッシブ発動に必要な通常攻撃を撃ち忘れないこと。

【ワンド】 ティオレー#

単純に回復量を増やすため、武器を “蛇龍の咆哮” に更新し、刻印装備を 2 段階超越させました。

細かい所だと武器に “クールタイム短縮率” を付け毎ローテ回復を撃てるようにしています。

【ランス】 ジェリコ#

自由枠。マニーとかでも良いと思いますが、デリエリのターンとクモの回転攻撃が重なったときに攻撃を優先したいため、シールド要員で採用しています。

スキルの CD が重いため武器に “クールタイム短縮率” を最大値で付けていますが、それでも毎ローテ撃てる訳ではないのが難しいところ。

武器に関しては 炎火 が良いのですが、持っていないので適当な武器を持たせています。

パーティのローテーション#

基本ローテーションは以下の通りです。

  1. ティオレー : スキル ➔ 特殊
  2. ジェリコ : スキル ➔ 特殊
  3. デリエリ : スイッチスキル 1 回目
  4. デイジー : スキル ×2 ➔ 特殊 ➔ 必殺
  5. デリエリ : スイッチスキル 2 回目 ➔ スキル ×2 ➔ 特殊 ×4 ➔ 必殺技 + デヴァステイター
  6. ティオレーに戻す
  • ティオレーの特殊攻撃は短押しして CD が表示される前にジェリコに切り替える
  • ジェリコの特殊攻撃は最終打撃が当たらないとシールド付与されない点に注意
  • デイジーのとき、どこかで通常攻撃・バックアタックできると良い
