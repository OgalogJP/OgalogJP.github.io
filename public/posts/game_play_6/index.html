ゲームシーズン・バーションなど#

ver 2.3

タラニスの聖地 (Transcendence) の攻略#

Transcendence はいくつか問題点があるので、簡単にさらっておきます。

主な問題点#

  • ボスの体力が非常に多い
  • 全体的に被ダメが大きい
  • パーティプレイはメンバー次第

ボスの体力が非常に多い#

アビスの比にならない程体力が多くなっています。半端な火力だと全く削れません。

全体的に被ダメが大きい#

特に ブラック・レディビショップ とラスボスの攻撃がかなり痛くなってます。

ラスボスの赤エフェクトの攻撃は何度も受けられないので、適宜回避・回復が必要になります。

パーティプレイはメンバー次第#

もしパーティプレイする際はパーティ募集でしっかりメンバーを厳選したほうが良いです。

何戦かパーティマッチングでプレイしましたが、適正外アタッカーがメンバーに居ると実質クリア不可能です。
( = 時間がかかりすぎる )

正直レイドのパーティプレイ時の難易度に関してはまだ調整の余地があると思います。

チェックメイトについて#

私の場合六時の方向から反時計回りに、戦闘エリアの右半分を破壊するようにしています。間に合えば左上 1 つまで破壊できます。この時の被ダメは HP 半分前後で十分に生存できます。

このギミックはマルチよりソロの方が安定して対処できます。理由は以下の通りです。

  • 停止攻撃の範囲が味方と被って見辛い
  • 味方の火力次第で破壊できるチェスピースの数が安定しない
  • マルチプレイ故のラグが深刻

停止攻撃は避けること前提です。これについては何度もプレイして慣れるしかありません。

【ワンド】 エスティア#

アプデで追加された新人。

必殺技を頻繁に撃たない場合、無凸で全然戦えます。

また回復量が凄まじく、タラニスの攻撃を耐えるのにかなり役立ちました。

汎用サポーターとして、今後いろいろな編成で見ることになりそうです。

パーティのローテーション#

基本ローテーションは以下の通り。

  1. エスティア : 特殊 ➔ スキル ➔ クイックスワップ
  2. エリザベス : スキル ➔ 特殊 ➔ クイックスワップ
  3. カラー : (貪欲 1 段階目発動) 特殊 (最速キャンセル) ➔ スキル (最速キャンセル) ➔ 必殺 ( ミラー:シェーパー付与 )
  4. デイジー : 特殊 (最速キャンセル) ➔ スキル ➔ クイックスワップ
  5. カラー : (貪欲 2 段階目発動) ※
  6. エスティアに戻る
  • ここで言う クイックスワップ とはスキルや特殊の直後にすぐキャラチェンをすること
  • 炎火 のデバフに関しては意識しなくて良いが、付与する場合 炎火持ち から入ること

※カラーのスキル回しについて#

ミラー:シェーパー付与後の流れは以下の通り。

  1. 特殊 ➔ スキル ➔ 必殺
  2. 通常攻撃 10hit ➔ 特殊 ➔ スキル ➔ 必殺
    or 特殊 ➔ スキル ➔ 通常 10hit ➔ 必殺
  3. 2 を 2~3 ループ
  • 特殊やスキルはダッシュでキャンセルができるため、状況次第で回避しながら回していく
    特殊やスキルのバフは撃った直後にかかるため、技の出し切りやヒットは必須ではない
  • シェーパ―の付与数に注意すること
    シェーパ-が3つ付与されている状態でスキル・特殊を撃つと上記のローテが狂う

キャラの代用#

  • エスティア out ➔ ティオレー in

回復量がかなり低下しますが、防御バフでタラニスのチェックメイトを耐えられる可能性があります。火力不足でチェックメイトを抜けられない場合の対抗策。

  • デイジー out ➔　ゴウセル in

持っている人はこっちの方が良いかもしれません。

クリアタイム#

クリアできたからいいものの、1 ステージに 50 分かかるのは中々堪えます。

タイムが縮まる可能性があるのは次の 3 点。

  • エリザベス・デイジーの刻印超越
    スイッチスキル後 10 秒間風属性ダメージ 30% アップ
  • 編成の調整
    特にゴウセルの影響が気になるところ
  • 編成キャラの凸 (カラー・エリザベス)
