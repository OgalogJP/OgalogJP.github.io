ゲーム

学園を舞台にした、生徒のもつ秘密をめぐるシュミレーション？ゲーム

学園生活シュミレータってわけではない

目的

“自分が楽しめるゲームであること” これが一番の目的

企画背景

とあるゲームの登場キャラからインスピレーションを受けた。
他人の秘密をいつの間にか知ってる

このゲームで得られる栄養素

  • NPC 同士で勝手に関係値が変わる
  • 特定 NPC への粘着行為
  • 陰キャが陽キャムーブしてもなんかうまくいかない感じ

コンセプト

秘密

このゲームの主題。この秘密をめぐってプレイヤーは NPC との会話、調査を行う。

秘密の伝播

NPC が持つ秘密は条件で伝播していく。NPC がもつ関係値、内部の性格パラメータによって決定する。
秘密には重さがある。

  • 軽い噂
  • そこそこ重たい秘密
  • 知りたくなかった重い秘密

重さの違いによって生徒間で伝播しやすかったり、まったくしなかったりする。重たい秘密はプレイヤーが自ら引き出す必要がある。

秘密の行使

プレイヤーが持つ秘密を話すことで関係値が変化したり、話し相手の秘密を引き出すことができる。
尚プレイヤーが持つ秘密であれば他人の秘密も話すことができる。

関係値

NPC 同士、NPC 対プレイヤーの間には関係値がある
この関係値次第で会話から秘密を聞けたり、逆にこちらから秘密を話すことで関係値が良くなったりする。

関係値の変化

ゲーム中主に以下のアクションで関係値が変化する

  • 会話
  • NPC の頼み事(=クエスト)

その他関係値の更新手段を追加で用意する予定

生きた世界

プレイヤーが何もしなくてもゲームが回る。基本的に NPC 同士の会話による関係値変動によってゲームに変化を与える。軽い噂であればプレイヤーが何もしなくても関手に伝播する。

ゲームプレイ

  • 繰り返しプレイできる、リプレイ性とランダム性
  • プレイヤーの立ち回り次第で 善・悪・中立 が可能
  • 何もしなくても回る生きた世界

ゲームシステム概要

  • NPC との会話で他生徒の秘密を知る
  • 秘密のやり取りで NPC 同士の関係値を上下
  • プレイヤーは持ってる秘密を行使し、NPC との会話を有利に進める
  • 会話以外でも観察・通りすがり、場所の調査で秘密を知ることができる

理想としては…

  • NPC との会話で秘密を集める( 陽キャムーブ )
  • 一切会話せず秘密を集める( 陰キャムーブ )
  • この両方で秘密を集める

この3パターンで遊べると良い

NPC の行動原理( AI方針 )

  • 学園内を歩かせ、NPC同士が接触したときアクションを決める( 軽い挨拶、雑談の開始など )
  • アクションの結果で NPC 同士の関係値を更新
  • 秘密を話す・伝播は NPC の関係値に基づいて決定する
  • NPC に性格パラメータを設定、この値から性格が決まり、各種行動に影響を与える
  • 各 NPC に1つ、直近の行動予定を設定する
    これはプレイヤーが特定の NPC と出逢いやすくするために用意する

  1. 指定学年からスタート
  2. 小ループ × 1か月 の長さ
  3. 卒業
  4. 何かしらのエンディング到達
  5. 希望学年に転生し 1 に戻る

  2. 休み1

ゲームマップ

学園全体を移動範囲とする。

主なロケーション

  • 食堂
  • 購買

マップデザインの背景

高校というより大学に近いイメージ。
一つ一つの建物を個別で作成・配置できることや、学園という閉じた空間でありながらも解放感を出すにはこれがいいと判断した。
