## 初めに
この記事は蛮族の族長デュラック ( Abyss ) の攻略について、私なりの攻略をまとめています。

### ゲームシーズン・バーションなど
ver 2.1 ハーフアニバーサリー後半

## 蛮族の族長デュラック ( Abyss ) の攻略
ここからは私なりの攻略について書いていきます。

- ボス HP 半分がライン
- 前半は優しめ
- 後半は高火力・即死に注意

尚有利属性の完凸・高凸キャラだと敵に付き合わず一瞬で倒せると思うので完全に別ゲーになると思います。

この記事の攻略は無凸・低凸向けの内容になります。

### ボスHP半分がライン
敵の動きはHP半分辺りを境に変化します。

### 前半
前半戦はそれほど脅威は有りません。シールドを割り、地道に削るだけです。ただ育成状況によっては被ダメが大きいため、避けられる攻撃は避けるようにします。

### 後半
このボスの問題は後半戦です。

被ダメがかなり大きく、防衛手段がない場合おそらく 3 回攻撃受けることができません。基本 2 回被弾すると死亡すると思って良いと思います。

最も多い死亡パターンは以下の流れです。

- 1回攻撃受けた時点で自身の HP がステージギミックの範囲内になる
- 2回目受けるところでステージギミックによる高火力で死亡する

また敵は当然スーパーアーマーでのけぞらないため、こちらの各種攻撃・必殺技中にもお構いなく攻撃してきます。そのため前半戦に比べて安全に敵にダメージを与えられる場面が激減します。

近距離火力でゴリ押すというのは敵・ステージギミックの構成上厳しいと思います。

敵の攻撃は全体的に大振りなため避けることは難しくないので、シンプルに避けて殴るか遠距離から安全にダメージを与えるのが戦いやすいです。

#### 【ガントレット】 ディアンヌ
大地パーティのバースター。

装備状況によるものでしょうが、バーストゲージの付与量が少なめな印象を受け、出場時間が長くなりがちです。ただヘビメタによるリアクション無効でストレスなく扱えるのは良い所です。

入場後は 必殺技➔スキル➔特殊攻撃➔通常攻撃➔特殊攻撃➔... と、バーストが溜まるまで殴り続けます。

#### 【剣盾】 デイジー
ハフバ復刻で追加した新戦力。元々はデリエリをより強く使うために引いたキャラでしたが、アタッカー運用も普通に強いです。

ただしバースト時に真価を発揮するキャラのため、バースト耐性が高い敵、やたらと動き回る敵、シールド有りの敵など苦手な敵が多いのが問題点。

#### 【ワンド】 ティオレー
[タラニスレイド](/posts/game_play_2) の時も紹介したヒーラー。

特殊攻撃の防御バフは短押しした後、クールダウン表示が出るまでにキャラチェンをすると、ティオレー自身が場に残り、防御バフ最大まで居残り続けてくれます。

ただしこの防御力バフはキングの刻印装備の効果誘発には使えません。

運用的には スイッチ➔回復➔特殊短押し➔キャラチェン といった感じになります。

#### 【ワンド】 キング
大地パーティ専用バッファー。専用だけあってバフ量が火力に大きく貢献します。

特に刻印装備と 1 凸効果が優秀です。

基本運用は スキル➔必殺技➔キャラチェン としています。

特殊攻撃の防御バフで刻印装備のクリダメ増加を誘発できますが、最大 5 秒程暇になるためあまり多用していません。

### パーティのローテーション

基本ローテーションは以下の通りです。

1. ティオレー : スキル ➔ 特殊短押し
2. キング : スキル ➔ 必殺
3. デイジー : スイッチスキル 1 回目
3. ディアンヌ : 必殺技 ➔ スキル ➔ ( 特殊攻撃 ➔ 通常攻撃 ) × バースト溜まるまで
4. デイジー : スイッチスキル 2 回目<br>
特殊攻撃 ➔ スキル ➔ ( 火力出し : 必殺技・スキル長押し・通常攻撃 ) × バースト無くなるまで
5. ティオレーに戻す

全体的にゴリ押し性能が高く、ディアンヌ、デイジーがリアクション無効を持つため安全に完走しやすいです。

厳密なところ、デイジーのスイッチスキル 1 回目から 2 回目の間 20 秒間以内にバーストさせる必要があるため、敵によっては貪欲装備 2 段階目の付与が難しい場合があります。

その他、スイッチスキルで気絶を狙える場合は積極的に狙う、明らかに避けられる攻撃は避けることを意識します。

#### ボス後半戦の立ち回り
上記のローテは前半戦を戦うには良いですが、後半戦は被ダメが大きいため厳しいです。

後半戦はローテというよりキャラ毎にやるべきことをやる感じで立ち回っていました。

- ディアンヌ : 攻撃を避け、隙を見つつバースト付与
- デイジー : バースト中に距離を取って必殺技を打つ・スキル長押しを当て逃げする
- ティオレー : 被弾時は回復に専念する
- キング : 余裕があるときに使う
