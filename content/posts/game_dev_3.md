## ClubSystem の目的
このライブラリはプレイヤーや NPC を部活に加入させたり、部長・副部長を選出するライブラリである。

- NPCを部活に割り当てる ( 入部処理 )
- 部活の割り当てを解除する ( 退部処理 )
- 部長・副部長の選出

## ライブラリが扱う概念

- [NPC](/posts/game_dev_9)
- 部活

### 部活とは
部活とはプレイヤーや NPC が所属・活動し、役職を持つ集団単位を表す抽象モデルである。

部活は生徒同士の会話でも部活に関する内容を話す際に参照される。

#### 仕様

- ゲーム中使用する部活は Common の Club.h に記載している
- 部内の生徒割合は ClubInfo を参照する割り当てアルゴリズムで決まる
- 部ごとに部長１人、副部長１人が選出される
- 全ての部が満員になるわけではない
- 生徒会のみ必ず満員になる

## ライブラリの責務
このライブラリの責務は部活に関する全般の処理である。具体的には以下のような処理を行う。

- 生徒への部活の割り当て
- 退部処理
- 部長・副部長の選出

## ライブラリの利用

- ゲーム初期化時、全生徒に対して一括で部活を割り当てる
- ゲーム初期化時や年度更新のタイミングで部長・副部長を選出する
- 個別の生徒に対して入部・退部処理を行う

## 設計
### データ構造

|モジュール|機能|
|---|---|
|ClubSystem|入部・退部処理、部長・副部長選出処理など|
|ClubAssignment|部活への割り当て|

#### ClubSystem
このライブラリの本体。具体的には次の処理が含まれている。

- 入部・退部処理 ( 集団 )
- 入部・退部処理 ( 個別 )
- プレイヤーの入部処理
- 部長・副部長の選出

部活加入に関する制限は CubInfo 構造体で管理している

- struct ClubInfo<br>
定員<br>
性別制限<br>
男子の目標比率<br>
部の最小人数<br>
部の定員レート<br>

#### ClubAssignment
部活への割り当てを専門に行うモジュール。

機械的に適当な割り当てを行うと部として見たとき不自然な割り当てになるため、専用の割り当てアルゴリズムを実装している。

部長・副部長の選出もここで行っている。

## ライブラリの拡張性

- 定員や性別制限など、部活加入に関する制限は各部毎に設定可能
- 割り当てアルゴリズム次第で部への割り当て具合を調整可能
- 各部の CubInfo は現状ハードコードされている

### 部活を増やすとき

- Club.h に部活を追加
- ClubAssignment に扱う部を追加<br>
部活を追加したことによるアルゴリズムの変更有無を確認する
- ハードコードのため、追加のたびリビルドする必要有り
